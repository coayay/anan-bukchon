# 경쟁사 후기 아카이브 — 누적 관리 규칙

안안(가회동 33-20) 경쟁 숙소의 실제 후기를 숙소별 1파일로 누적한다. 이 폴더가 원본이고, 통합 분석은 상위 `research/competitor-review-analysis.md`의 13개 축을 코딩 프레임으로 쓴다.

## 1. 폴더 구조

- `README.md` — 이 문서 (규칙 · 입력 템플릿 · 인덱스)
- `YYYY-MM-DD_숙소명_리스팅ID.md` — 숙소별 정제 원본 + 통계 + 안안 시사점
- `YYYY-MM-DD_숙소명_리스팅ID.csv` — 같은 내용의 표 (노션 DB 임포트용)

날짜는 수집일. 같은 숙소를 다시 수집하면 새 날짜 파일을 만들고 인덱스에 두 줄을 남긴다 (변화 추적).

## 2. 후기 전달 방법 (권장 순서)

**최선: 구글 독스 1개 파일에 여러 숙소를 누적** (2026-09-10 검증 완료). Claude가 구글 드라이브에서 직접 읽는다. 링크만 주면 된다.

문서 안에서 숙소마다 아래 5줄 헤더를 쓰고 그 아래 후기를 붙여 넣는다. 헤더 형식만 지키면 숙소가 몇 개든 자동으로 분리·집계된다.

```
숙소명: 
숙소 URL: https://www.airbnb.co.kr/rooms/
구분 : 최대 인원 O명침실 O개침대 O개욕실 O개
기타 : (앞집 / 뒷집 / 인근 숙소 등 안안 기준 위치)
후기 전체 복사:
```

붙여넣기 요령
- 리스팅 상단의 **평점 요약 블록**(4.98, 별점 분포 %, 청결도·정확도·체크인·의사소통·위치·가격 대비 만족도, 게스트 언급 키워드)을 후기보다 먼저 함께 복사한다. 세부 평점은 후기 본문에서 얻을 수 없는 정보라 가치가 크다.
- "후기 전체 보기" → 정렬을 **최신순**으로 바꾸고 **끝까지 스크롤한 뒤** 전체 드래그 복사. 스크롤이 덜 되면 일부만 복사된다 (2026-09-10 클래식고택 156건 중 108건, 현현재 77건 중 60건이 이렇게 누락됐다).
- 호스트 답글도 함께 복사한다. 응대 SOP 분석에 쓴다.
- 자동 번역본 그대로 두면 된다.

차선: 메모장 .txt 파일 업로드 (같은 헤더 사용). 30건 이하 소량은 채팅에 바로 붙여도 된다.
